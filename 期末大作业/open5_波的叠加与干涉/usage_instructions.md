# 开放应用题5A：波的叠加与干涉 - 使用说明

## 使用说明

### 环境配置
1. **安装Python**：确保安装了Python 3.7或更高版本
2. **安装依赖包**：
   ```bash
   pip install numpy matplotlib ipywidgets jupyter streamlit
   ```

### 运行方法

#### 方法1：在Jupyter Notebook中运行
1. **启动Jupyter Notebook**：
   ```bash
   jupyter notebook
   ```
2. **打开代码文件**：在Jupyter Notebook中打开 `open5.py` 文件
3. **运行代码**：点击"运行"按钮或使用快捷键 `Shift+Enter` 运行整个代码
4. **交互操作**：
   - 代码运行后会生成三个交互式控件区域，分别对应"波的叠加"、"驻波"和"二维波的干涉"
   - 使用滑块调整各个参数（频率、振幅、相位、时间）
   - 调整参数时，图像会实时更新，观察波的叠加和干涉现象的变化

#### 方法2：运行Streamlit网页应用
1. **启动Streamlit应用**：
   ```bash
   streamlit run streamlit_app.py
   ```
2. **在浏览器中访问**：Streamlit会自动打开浏览器窗口，显示交互图像网站
3. **交互操作**：
   - 在左侧侧边栏选择可视化类型（波的叠加、驻波、二维波的干涉）
   - 使用滑块调整各个参数（频率、振幅、相位、时间）
   - 调整参数时，图像会实时更新，观察波的叠加和干涉现象的变化
   - 查看底部的物理原理说明，了解相关概念

### 参数说明
| 参数 | 范围 | 说明 |
|------|------|------|
| 频率 | 0.1-5.0 Hz | 波的振荡频率，影响波的周期和波长 |
| 振幅 | 0.1-2.0 | 波的最大振幅，影响波的强度 |
| 相位 | 0-2π rad | 波的初始相位，影响波的起始位置 |
| 时间 | 0-2.0 s | 观察时间点，影响波的传播状态 |

## 截图说明

### 截图1：波的叠加（同频率同相位）
- **参数设置**：波1频率=1.0 Hz，波2频率=1.0 Hz，波1振幅=1.0，波2振幅=1.0，波1相位=0.0 rad，波2相位=0.0 rad，时间=0.0 s
- **观察效果**：两个波同相位叠加，形成振幅为2.0的波，展示了相长干涉现象
- **物理意义**：同频率同相位的波叠加时，振幅相加，能量增强

### 截图2：驻波
- **参数设置**：频率=1.0 Hz，振幅=1.0，相位=0.0 rad，时间=0.0 s
- **观察效果**：显示了驻波的波形，标记了波节位置（振幅为零的点）
- **物理意义**：驻波是由两列频率相同、振幅相同、传播方向相反的波叠加形成的，波形不移动，仅在原地振动

### 截图3：二维波的干涉
- **参数设置**：波源1频率=1.0 Hz，波源2频率=1.0 Hz，波源1振幅=1.0，波源2振幅=1.0，波源1相位=0.0 rad，波源2相位=0.0 rad，时间=0.0 s
- **观察效果**：显示了两个波源产生的二维干涉图样，形成明暗相间的条纹
- **物理意义**：二维波的干涉是由两个相干波源发出的波在空间叠加形成的，明条纹对应相长干涉，暗条纹对应相消干涉
