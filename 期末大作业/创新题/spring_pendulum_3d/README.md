# 3D弹簧-单摆耦合系统交互式模型

## 项目简介

本项目实现了一个3D弹簧-单摆耦合系统的交互式模型，用于帮助同学们学习分析力学时理解复杂的耦合振动现象。系统允许用户通过滑块控件调整滑块位置和小球角度，实时观察系统的3D状态变化。

## 功能特点

- 3D弹簧-单摆耦合系统物理模型
- 滑块水平方向位置调整
- 单摆小球3D空间角度调整
- 交互式参数调整（底部滑块控件）
- 实时3D模型更新
- 中文界面支持

## 使用方法

### 直接运行

```bash
python spring_pendulum_3d.py
```

这将启动交互式3D模型，显示一个包含3D可视化区域和底部参数控制区域的窗口。

### 参数调整方法

1. **滑块离左边长度**：通过底部第一个滑块调整，范围为-2到2米
2. **小球极角**：通过底部第二个滑块调整，范围为0到π弧度
3. **小球方位角**：通过底部第三个滑块调整，范围为-π到π弧度
4. **实时更新**：调整完成后释放鼠标，3D模型会立即更新

## 参数说明

| 参数 | 范围 | 说明 |
|------|------|------|
| 滑块离左边长度 | -2.0-2.0 | 滑块水平位置 (m) |
| 小球极角 | 0.0-π | 单摆与垂直方向的夹角 (rad) |
| 小球方位角 | -π-π | 单摆在水平面上的投影与x轴的夹角 (rad) |

## 物理原理

### 3D弹簧-单摆耦合系统模型

系统由一个沿水平方向移动的滑块和一个悬挂在滑块上的单摆组成。通过调整滑块位置和单摆角度，可以观察系统在不同状态下的构型。

### 小球位置计算

小球在3D空间中的位置由以下公式计算：
- \( x = \text{滑块位置} + l \sin\theta \cos\phi \)
- \( y = l \sin\theta \sin\phi \)
- \( z = -l \cos\theta \)

其中：
- \( l \) 是单摆长度
- \( \theta \) 是小球极角
- \( \phi \) 是小球方位角
