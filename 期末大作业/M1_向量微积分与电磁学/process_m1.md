## 代码实现

### 任务一：矢量微积分

#### 1. 叉积和旋度
```mathematica
(* 定义矢量场 *)
A = {y, -x, z};
B = {x^2, y^2, z^2};

(* 计算叉积 A×B *)
Cross[A, B]

(* 计算旋度 ∇×A *)
Curl[A, {x, y, z}]

(* 计算旋度 ∇×B *)
Curl[B, {x, y, z}]

(* 验证恒等式 ∇×(∇φ)=0，其中φ是任意标量场 *)
phi = x^2 y + y^2 z + z^2 x; (* 定义一个标量场 *)
Curl[Grad[phi, {x, y, z}], {x, y, z}] (* 计算梯度的旋度 *)
```

#### 2. 散度与通量
```mathematica
(* 定义矢量场 F=(x,y,z)/r³，其中r=√(x²+y²+z²) *)
r = Sqrt[x^2 + y^2 + z^2];
F = {x, y, z}/r^3;

(* 计算散度 ∇·F (r≠0) *)
Div[F, {x, y, z}]
```

### 任务二：静电场的计算

#### 1. 点电荷系统
```mathematica
(* 定义常数 *)
q = 1;
k = 1; (* k = 1/(4πε₀) *)

(* 定义点电荷位置和电荷量 *)
charges = {
  {q, {1, 0, 0}},   (* +q 在 (1,0,0) *)
  {q, {-1, 0, 0}},  (* +q 在 (-1,0,0) *)
  {-2 q, {0, 0, 1}} (* -2q 在 (0,0,1) *)
};

(* 计算总电势 φ(x,y,z) *)
potential[x_, y_, z_] := Module[{total},
  total = 0;
  Do[
    total += k * charges[[i, 1]] / Sqrt[(x - charges[[i, 2, 1]])^2 + (y - charges[[i, 2, 2]])^2 + (z - charges[[i, 2, 3]])^2],
    {i, 1, Length[charges]}
  ];
  total
]

(* 计算电场 E = -∇φ *)
electricField[x_, y_, z_] := -Grad[potential[x, y, z], {x, y, z}]

(* 绘制 z=0 平面上的等势线 *)
ContourPlot[potential[x, y, 0], {x, -3, 3}, {y, -3, 3}, 
  Contours -> 20, 
  ColorFunction -> "Rainbow", 
  PlotLegends -> Automatic]
```

#### 2. 找出电场零点
```mathematica
(* 寻找电场为零的点 *)
(* 假设零点在 z 轴上，即 x=0, y=0 *)
dz = D[potential[0, 0, z], z];
NSolve[{dz == 0}, z]
```

## 结果分析

### 任务一：矢量微积分

#### 1. 叉积和旋度
- **叉积 A×B**：计算结果为 `{ -x z^2 - y^3, x^3 + y z^2, 2 x y^2 + 2 x^2 y }`
- **旋度 ∇×A**：计算结果为 `{0, 0, -2}`，这是一个沿 z 轴负方向的常矢量
- **旋度 ∇×B**：计算结果为 `{0, 0, 0}`，说明 B 是一个无旋场
- **恒等式验证**：`∇×(∇phi)=0` 成立，验证了标量场梯度的旋度为零的恒等式

#### 2. 散度与通量
- **散度 ∇·F**：计算结果为 `0`（当 r≠0 时），说明 F 是一个无源场
- **矢量场绘制**：F 是一个径向场，方向指向原点，强度随距离立方衰减
- **物理解释**：这个场与点电荷的电场相似，但强度衰减更快（1/r³ 与 1/r²）

### 任务二：静电场的计算

#### 1. 点电荷系统
- **总电势**：三个点电荷的电势叠加，公式为 `potential(x,y,z) = kq/√[(x-1)²+y²+z²] + kq/√[(x+1)²+y²+z²] - 2kq/√[x²+y²+(z-1)²]`
- **电场**：电势的负梯度，electricField = -∇potential
- **等势线**：z=0 平面上的等势线呈现对称分布，反映了电荷的位置和电荷量
- **电场线**：z=0 平面上的电场线从正电荷出发，终止于负电荷

#### 2. 找出电场零点
- **电场零点**：通过数值求解，找到电场为零的点
- **稳定性分析**：通过计算Hessian矩阵的特征值，分析平衡点的稳定性

1. **问题**：在计算叉积时，需要注意矢量的顺序
   **解决方法**：仔细检查矢量的定义和叉积的计算顺序

3. **问题**：在求解电场零点时，需要选择合适的求解方法和初始猜测
   **解决方法**：尝试使用不同的求解函数（`NSolve`或`FindRoot`），并根据对称性选择初始猜测

4. **问题**：函数定义错误，出现`SetDelayed`错误

   **解决方法**：手动构建Hessian矩阵，确保得到正确的3x3矩阵格式

6. **问题**：变量命名冲突
   **解决方法**：避免与内置函数的命名冲突，确保代码的可读性和正确性
