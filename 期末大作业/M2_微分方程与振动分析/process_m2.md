```mathematica
m = 1;
k = 1;
diffEq = m x''[t] + γ x'[t] + k x[t] == 0;

(* 初始条件 *)
initCond = {x[0] == 1, x'[0] == 0};

(* 情况1：欠阻尼 γ=0.2 *)

sol1 = DSolve[{diffEq /. γ -> γ1, initCond}, x[t], t][[1]]

(* 情况2：临界阻尼 γ=2 *)

sol2 = DSolve[{diffEq /. γ -> γ2, initCond}, x[t], t][[1]]

(* 情况3：过阻尼 γ=4 *)
γ3 = 4;
sol3 = DSolve[{diffEq /. γ -> γ3, initCond}, x[t], t][[1]]
```

### 任务二：简单受迫振动

#### 1. 稳态响应
```mathematica
(* 定义受迫振动的微分方程 *)
m = 1;
k = 1;
γ = 0.2;
F0 = 1;
diffEqForced = m x''[t] + γ x'[t] + k x[t] == F0 Cos[ω t];

(* 求解通解并提取稳态解 *)
steadyStateSol = x[t] /. DSolve[diffEqForced, x[t], t][[1]] /. C[1] -> 0 /. C[2] -> 0

(* 计算稳态振幅 A(ω) *)
Aω = FullSimplify[Sqrt[Coefficient[steadyStateSol, Cos[ω t]]^2 + Coefficient[steadyStateSol, Sin[ω t]]^2]]

(* 绘制振幅-频率响应曲线 *)
Plot[
  Aω,
  {ω, 0, 3},
  PlotStyle -> {Purple, Thick},
  AxesLabel -> {"驱动频率 ω (rad/s)", "稳态振幅 A(ω)"}
]

(* 计算共振频率和最大振幅 *)
ω0 = Sqrt[k/m];
ωr = Sqrt[ω0^2 - (γ/(2m))^2]
Amax = Aω /. ω -> ωr
```

#### 2. 数值求解
```mathematica
(* 定义初始条件 *)
initCondForced = {x[0] == 0, x'[0] == 0};

(* 定义驱动频率列表 *)
ωList = {0.5, 1.0, 1.5};

(* 使用NDSolve求解不同ω下的解 *)
solNDSolveList = Table[
  NDSolve[{diffEqForced /. ω -> ωi, initCondForced}, x[t], {t, 0, 20}],
  {ωi, ωList}
];

(* 绘制不同ω下的x(t)曲线 *)
Plot[
  Evaluate[Table[x[t] /. solNDSolveList[[i, 1]], {i, Length[ωList]}]],
  {t, 0, 20},
  PlotLegends -> Table["ω = " <> ToString[ωi], {ωi, ωList}],
  PlotStyle -> {{Red, Thick}, {Blue, Thick}, {Green, Thick}},
  AxesLabel -> {"时间 t (s)", "位移 x(t)"}
]
```

## 结果分析

### 任务一：阻尼振动的完整分析

#### 1. 解析解
- **通解形式**：阻尼谐振子的通解形式取决于阻尼系数 γ 与临界阻尼系数 γc = 2√(mk) 的关系
- **三种阻尼情况**：
  - **欠阻尼 (γ=0.2)**：解为衰减振荡形式，`x(t) = e^(-γt/(2m))(C1 cos(ωd t) + C2 sin(ωd t))`，其中 `ωd = √(ω0^2 - (γ/(2m))^2)` 是阻尼振动频率
  - **临界阻尼 (γ=2)**：解为临界衰减形式，`x(t) = e^(-ω0 t)(C1 + C2 t)`，系统最快回到平衡位置
  - **过阻尼 (γ=4)**：解为过衰减形式，`x(t) = C1 e^(r1 t) + C2 e^(r2 t)`，其中 r1 和 r2 是两个负实根，系统缓慢回到平衡位置

#### 2. 可视化比较
- **位移曲线**：
  - 欠阻尼：呈现衰减振荡，振幅逐渐减小，频率低于固有频率
  - 临界阻尼：无振荡，最快回到平衡位置
  - 过阻尼：无振荡，缓慢回到平衡位置，比临界阻尼慢
- **相空间轨迹**：
  - 欠阻尼：螺旋线，逐渐收敛到原点
  - 临界阻尼：抛物线，直接收敛到原点
  - 过阻尼：曲线，缓慢收敛到原点

### 任务二：简单受迫振动

#### 1. 稳态响应
- **稳态解形式**：受迫振动的稳态解是与驱动力同频率的余弦函数，`x(t) = A(ω) cos(ω t - φ)`，其中 A(ω) 是振幅，φ 是相位差
- **幅频响应曲线**：
  - 当驱动频率 ω 远小于固有频率 ω0 时，振幅趋近于 F0/k
  - 当驱动频率 ω 等于共振频率 ωr 时，振幅达到最大值
  - 当驱动频率 ω 远大于固有频率 ω0 时，振幅趋近于 0
- **共振频率和最大振幅**：
  - 共振频率 `ωr = √(ω0^2 - (γ/(2m))^2) = √(1 - 0.01) = √0.99 ≈ 0.995 rad/s`
  - 最大振幅 `Amax ≈ 5.025`

#### 2. 数值求解
- **过渡过程**：
  - 初始时刻，系统从静止开始，位移逐渐增大
  - 经过一段时间后，暂态项衰减，系统进入稳态振动
  - 稳态振动的频率与驱动力频率相同
- **不同驱动频率的响应**：
  - ω=0.5：驱动频率低于共振频率，振幅较小，相位差较小
  - ω=1.0：驱动频率接近共振频率，振幅较大，过渡过程明显
  - ω=1.5：驱动频率高于共振频率，振幅较小，相位差较大

## 物理意义解释

### 三种阻尼类型的物理意义

1. **欠阻尼 (γ < γc)**
   - 物理意义：阻尼较小，系统在回到平衡位置前会振荡多次
   - 应用场景：钟摆、弹簧振子、电路中的 LC 振荡
   - 特点：能量逐渐耗散，振幅按指数规律衰减

2. **临界阻尼 (γ = γc)**
   - 物理意义：阻尼刚好使系统无振荡地最快回到平衡位置
   - 应用场景：电表指针、汽车减震系统、精密仪器的阻尼设计
   - 特点：无振荡，响应速度最快

3. **过阻尼 (γ > γc)**
   - 物理意义：阻尼过大，系统缓慢回到平衡位置，无振荡
   - 应用场景： door closers、液压阻尼器
   - 特点：响应缓慢，无振荡

### 共振现象

- **定义**：当驱动力频率接近系统固有频率时，受迫振动的振幅达到最大值的现象
- **物理机制**：驱动力与系统振动同相位，驱动力持续对系统做功，使振幅增大
- **共振条件**：驱动频率 ω ≈ 共振频率 ωr = √(ω0^2 - (γ/(2m))^2)
- **应用场景**：
  - 音乐：乐器共鸣、音响系统
  - 工程：桥梁设计（避免共振）、地震防护
  - 科学研究：核磁共振、电子自旋共振
- **危害**：共振可能导致结构破坏，如桥梁坍塌、机器损坏
